> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give pluton a PBR-shaped material model with per-side face materials, translucency, full material editing under undo, drag-to-paint, and a Color-by-Tag view mode.

**Architecture:** The material model stays pure Python in `model/material.py`; the renderer approximates its PBR parameters with the existing Blinn-Phong shader. Faces gain independent front and back material slots in `Scene`, batching keys on the `(front, back)` pair, and translucent faces draw in a second pass sorted back to front. Every piece of hard logic (the PBR mapping, the batch plan, the sort) is a pure function testable with no `QApplication` and no GL context.

**Tech Stack:** Python 3.13, PySide6 (Qt 6), moderngl / PyOpenGL, numpy, pytest + pytest-qt. C++20 half-edge kernel via nanobind, untouched by this milestone except for the version bump.

**Spec:** `docs/2026-09-08-M7.5a-materials-design.md`. The plan argues from the spec; read both.

### Seven corrections the spec does not carry

Found by reading the code while writing this plan. Where these conflict with the spec, **the plan is correct** and the spec's §8 history records it in Task 13.

1. **The translucent sort cannot be scene-global.** Face buffers are per-definition, cached in `ScenePreviewRenderer._def_buffers`, and `model.traverse_visible()` yields definitions in arbitrary order. A scene-wide back-to-front face sort would need a scene-wide translucent buffer, which the spec did not budget. This plan sorts faces **within** a definition, and sorts **definitions among themselves** by world-space centroid distance. Two interpenetrating translucent groups therefore sort by centroid rather than per face. Stated as a limitation, not fixed.
2. **The draw loop must split into two traversals.** Today one loop draws each definition's faces then its edges (`scene_renderer.py:517-556`). Translucent faces must come after *all* opaque geometry across *all* definitions, so pass 1 walks every definition drawing opaque batches and edges, and pass 2 walks definitions sorted back to front drawing only translucent batches. The spec said "two passes" without noting it restructures the traversal.
3. **`phong_material_for` must stay primitive-typed.** `render_style.py` deliberately imports nothing from the model layer, and `model/material.py` carries a comment about avoiding the reverse import; the renderer duck-types `getattr(model, "materials", None)`. So the signature becomes `phong_material_for(base_color, *, metallic, roughness)`, **not** `phong_material_for(material)`.
4. **`resolve_face_pass` already returns `blend` and `depth_write`,** so per-side resolution is nearly free: call it once per side and combine. But `blend` and `depth_write` are per-**batch** properties, not per-side, so they are derived from whichever side is more translucent.
5. **`face_materials` in the file format is keyed by face *index*, not face id** (`io/document_codec.py:41-48`), and only non-Default entries are written. The back side follows the same convention in a sibling dict.
6. **A guard test pins `render_style._DEFAULT_SPECULAR` / `_DEFAULT_SHININESS` against `scene_renderer._MATERIAL_SPECULAR` / `_MATERIAL_SHININESS`.** The PBR mapping makes specular and shininess *derived* rather than constant, so that guard must be revisited deliberately in Task 2 rather than tripped over later.
7. **Painting Default clears the dict entry** rather than storing 0 (`scene.py:470`, `material_commands.py:_apply`). The face-material dicts therefore hold only painted faces, which is exactly what `DeleteMaterialCommand` scans to find affected faces.

In `python/pluton/model/material.py`, extend the dataclass and add the library methods. `edit` builds a new frozen record with `dataclasses.replace`, which raises `TypeError` on an unknown field for free, satisfying the rejection test without hand-written validation.

```python
from dataclasses import dataclass, replace


@dataclass(frozen=True, slots=True)
class Material:
    """A named material. `base_color` is RGB in 0..1; alpha 1.0 is opaque."""

    id: int
    name: str
    base_color: tuple[float, float, float]
    alpha: float = 1.0
    metallic: float = 0.0
    roughness: float = 0.5

    @property
    def is_translucent(self) -> bool:
        return self.alpha < 1.0
```

On `MaterialLibrary`:

```python
    def edit(self, mid: int, **fields) -> Material:
        """Replace the material with an edited copy. Unknown fields raise TypeError."""
        edited = replace(self._materials[mid], **fields)
        self._materials[mid] = edited
        if mid == self.DEFAULT_ID:
            self._default = edited
        return edited

    def index_of(self, mid: int) -> int:
        """Position of `mid` in display order."""
        return self._order.index(mid)

    def remove(self, mid: int) -> Material:
        """Drop a material and return it. Refuses Default, the unpainted fallback."""
        if mid == self.DEFAULT_ID:
            raise ValueError("the Default material cannot be removed")
        removed = self._materials.pop(mid)
        self._order.remove(mid)
        return removed

    def restore(self, material: Material, index: int) -> None:
        """Put a removed material back at `index` in display order (undo)."""
        self._materials[material.id] = material
        self._order.insert(index, material.id)
```

Update `to_records` and `from_records`:

```python
    def to_records(self) -> list[dict]:
        return [
            {
                "id": m.id,
                "name": m.name,
                "base_color": list(m.base_color),
                "alpha": m.alpha,
                "metallic": m.metallic,
                "roughness": m.roughness,
            }
            for m in self.materials()
        ]

    @classmethod
    def from_records(cls, records: list[dict], next_id: int) -> MaterialLibrary:
        """Rebuild authoritatively from saved records (no auto-seed).

        Accepts the schema <= 4 shape, which wrote "color" and carried no PBR
        fields; those default to an opaque dielectric.
        """
        lib = cls()
        lib._materials = {}
        lib._order = []
        for r in records:
            color = r.get("base_color", r.get("color"))
            mat = Material(
                int(r["id"]),
                str(r["name"]),
                (float(color[0]), float(color[1]), float(color[2])),
                alpha=float(r.get("alpha", 1.0)),
                metallic=float(r.get("metallic", 0.0)),
                roughness=float(r.get("roughness", 0.5)),
            )
            lib._materials[mat.id] = mat
            lib._order.append(mat.id)
        lib._default = lib._materials.get(cls.DEFAULT_ID, lib._default)
        lib._next_id = int(next_id)
        return lib
```

```python
@dataclass(frozen=True, slots=True)
class FaceBatch:
    """A contiguous run of same-(front, back)-material vertices in the VBO."""

    front_material_id: int
    back_material_id: int
    first: int  # first vertex index
    count: int  # vertex count (a multiple of 3)


@dataclass(frozen=True, slots=True)
class BatchPlan:
    """The reordering and the two batch lists it produces."""

    vertex_order: np.ndarray
    opaque: list[FaceBatch]
    translucent: list[FaceBatch]
    translucent_first: int


_ID_BITS = 20  # material ids are monotonic and small; 1M per side is ample


def plan_face_batches(
    front_ids: Sequence[int],
    back_ids: Sequence[int],
    translucent_mids: frozenset[int] = frozenset(),
) -> BatchPlan:
    """Stable-sort triangles by (is_translucent, front, back) into batches.

    Because translucency leads the key, translucent triangles land as a
    contiguous suffix of `vertex_order`, starting at `translucent_first`.
    Task 5 re-permutes only that range and Task 6 re-uploads only that slice,
    so the suffix property is load-bearing rather than incidental.

    A triangle is translucent when EITHER of its side materials is (spec D5).
    """
    front = np.asarray(front_ids, dtype=np.int64)
    back = np.asarray(back_ids, dtype=np.int64)
    t = int(front.shape[0])
    if int(back.shape[0]) != t:
        raise ValueError(f"front/back length mismatch: {t} vs {int(back.shape[0])}")
    if t == 0:
        return BatchPlan(np.zeros(0, dtype=np.int64), [], [], 0)

    if translucent_mids:
        tl = np.fromiter(translucent_mids, dtype=np.int64, count=len(translucent_mids))
        is_tl = np.isin(front, tl) | np.isin(back, tl)
    else:
        is_tl = np.zeros(t, dtype=bool)

    key = (is_tl.astype(np.int64) << (2 * _ID_BITS)) | (front << _ID_BITS) | back
    tri_order = np.argsort(key, kind="stable")
    vertex_order = (tri_order[:, None] * 3 + np.arange(3)).reshape(-1).astype(np.int64)

    sorted_key = key[tri_order]
    sorted_front = front[tri_order]
    sorted_back = back[tri_order]
    sorted_tl = is_tl[tri_order]

    opaque: list[FaceBatch] = []
    translucent: list[FaceBatch] = []
    _, starts = np.unique(sorted_key, return_index=True)
    for k in range(len(starts)):
        tri_start = int(starts[k])
        tri_end = int(starts[k + 1]) if k + 1 < len(starts) else t
        batch = FaceBatch(
            front_material_id=int(sorted_front[tri_start]),
            back_material_id=int(sorted_back[tri_start]),
            first=tri_start * 3,
            count=(tri_end - tri_start) * 3,
        )
        (translucent if bool(sorted_tl[tri_start]) else opaque).append(batch)

    translucent_first = translucent[0].first if translucent else t * 3
    return BatchPlan(vertex_order, opaque, translucent, translucent_first)
```

`np.unique` returns ascending keys and the translucency bit is the most significant, so opaque batches enumerate first and `translucent[0].first` is genuinely the suffix start.

```python
"""Back-to-front ordering for the translucent pass (M7.5a).

Pure numpy, no GL and no Qt, so it is fully unit-testable headlessly. Used at
two granularities: triangles within one definition, and definitions within the
scene. `order_back_to_front` serves both.

Transforms are COLUMN-VECTOR (`M @ [p; 1]`), matching sweep_stations and
build_mesh_into_scene.
"""

from __future__ import annotations

import numpy as np


def triangle_centroids(positions: np.ndarray) -> np.ndarray:
    """(3T, 3) vertex positions in triangle order -> (T, 3) centroids."""
    pts = np.asarray(positions, dtype=np.float64)
    if pts.shape[0] == 0:
        return np.zeros((0, 3), dtype=np.float64)
    return pts.reshape(-1, 3, 3).mean(axis=1)


def transform_points(points: np.ndarray, matrix: np.ndarray) -> np.ndarray:
    """Apply a 4x4 column-vector transform to (N, 3) points."""
    pts = np.asarray(points, dtype=np.float64)
    if pts.shape[0] == 0:
        return np.zeros((0, 3), dtype=np.float64)
    m = np.asarray(matrix, dtype=np.float64)
    homogeneous = np.concatenate([pts, np.ones((pts.shape[0], 1))], axis=1)
    return (homogeneous @ m.T)[:, :3]


def order_back_to_front(points_world: np.ndarray, camera_pos: np.ndarray) -> np.ndarray:
    """Indices of `points_world` ordered farthest from the camera first.

    Squared distance is enough: the ordering is identical and the sqrt is not.
    """
    pts = np.asarray(points_world, dtype=np.float64)
    if pts.shape[0] == 0:
        return np.zeros(0, dtype=np.int64)
    delta = pts - np.asarray(camera_pos, dtype=np.float64).reshape(1, 3)
    d2 = np.einsum("ij,ij->i", delta, delta)
    return np.argsort(-d2, kind="stable").astype(np.int64)


def triangle_order_to_vertex_order(tri_order: np.ndarray) -> np.ndarray:
    """(T,) triangle permutation -> (3T,) vertex permutation."""
    order = np.asarray(tri_order, dtype=np.int64)
    if order.shape[0] == 0:
        return np.zeros(0, dtype=np.int64)
    return (order[:, None] * 3 + np.arange(3)).reshape(-1).astype(np.int64)
```

`(homogeneous @ m.T)` is the batched form of `m @ column`; writing it this way avoids a transpose of the whole point array.

  ```python
class AddMaterialCommand(Command):
  ```

```python
    name = "Add Material"

    def __init__(self, library, name_: str, base_color) -> None:
        self._lib = library
        self._name = name_
        self._color = base_color
        self._mid: int | None = None
        self._removed = None

    @property
    def material_id(self) -> int:
        assert self._mid is not None, "material_id read before do()"
        return self._mid

    def do(self, scene) -> None:
        if self._mid is None:
            self._mid = self._lib.add_custom(self._name, self._color).id
        else:
            # redo: put the same record back at the end, preserving its id
            self._lib.restore(self._removed, len(self._lib.materials()))

    def undo(self, scene) -> None:
        self._removed = self._lib.remove(self._mid)

    name = "Edit Material"

        self._lib = library
        self._mid = material_id
        self._fields = fields
        self._before = None

    def do(self, scene) -> None:
        self._before = self._lib.get(self._mid)
        self._lib.edit(self._mid, **self._fields)

    def undo(self, scene) -> None:
        self._lib.edit(

            name=self._before.name,
            base_color=self._before.base_color,
            alpha=self._before.alpha,
            metallic=self._before.metallic,
            roughness=self._before.roughness,
        )


class DeleteMaterialCommand(Command):
    """Remove a material and repaint every side using it back to Default.

    `affected_count` is readable before do() so the confirmation dialog can
    quote it and the user can still cancel.
    """

    name = "Delete Material"

    def __init__(self, library, material_id: int, scene) -> None:
        if material_id == 0:
            raise ValueError("the Default material cannot be deleted")
        self._lib = library
        self._mid = material_id
        self._affected = scene.faces_with_material(material_id)
        self._record = None
        self._index = -1

    @property
    def affected_count(self) -> int:
        return len(self._affected)

    def do(self, scene) -> None:
        self._index = self._lib.index_of(self._mid)
        self._record = self._lib.remove(self._mid)
        for f_id, side in self._affected:
            scene.clear_face_material(f_id, side)

    def undo(self, scene) -> None:
        self._lib.restore(self._record, self._index)
        for f_id, side in self._affected:
            scene.set_face_material(f_id, self._mid, side)
```

**Side resolution.** `_pick_face` returns a face id via `pick_selectable`. To decide which side was clicked, take the world-space face normal and dot it with the world-space ray direction: facing the normal means the front. Re-crossing a face already at the target material and side is a no-op, so a wobbling cursor does not bloat the composite.

```python
def side_for_ray(world_normal, ray_direction) -> Side:
    """Which side of a face a ray hits.

    A ray travelling against the normal strikes the front. `world_normal` must
    already be in world space, transformed by the inverse-transpose of the
    world matrix's linear block (see model.pick_face_local, fixed in M7.4 #92):
    the plain linear block gives the wrong side under a non-uniform scale.
    """
    return Side.FRONT if float(np.dot(world_normal, ray_direction)) < 0.0 else Side.BACK
```

```python
    def _begin_stroke(self, material_id: int) -> None:
        self._stroke_commands = []
        self._stroke_painted = set()

    def _paint_during_stroke(self, f_id: int, side: Side, material_id: int) -> None:
        if (f_id, side) in self._stroke_painted:
            return
        if self._scene.face_material(f_id, side) == material_id:
            self._stroke_painted.add((f_id, side))
            return
        cmd = PaintFaceCommand(f_id, material_id, side)
        cmd.do(self._scene)          # eager, so the paint appears live
        self._stroke_commands.append(cmd)
        self._stroke_painted.add((f_id, side))

    def _end_stroke(self) -> None:
        if self._stroke_commands and self._command_stack is not None:
            composite = CompositeCommand(self._stroke_commands, name="Paint")
            self._command_stack.push_executed(composite, self._scene)
        self._stroke_commands = []
        self._stroke_painted = set()
```
