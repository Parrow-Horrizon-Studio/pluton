# glTF test fixtures (M6c)

- **plain_box.glb** — a minimal uncompressed unit-cube GLB, generated
  programmatically for Pluton's tests (no third-party content).
- **draco_box.glb** — the Khronos **Box** sample with
  `KHR_draco_mesh_compression`, packed from the `glTF-Draco` variant
  (`Box.gltf` + `Box.bin`) into a single self-contained `.glb`.
  Source: <https://github.com/KhronosGroup/glTF-Sample-Assets> (Models/Box).
  License: **CC0 1.0 (public domain)** — Khronos sample asset.

`draco_box.glb` is the fixture behind the permanent Draco CI gate: it must
decode on every run, guarding that the Assimp dependency still provides Draco
support.

- **uvgrid.png** - a 4x4 RGBA marker image generated by `make_fixtures.py`.
  Red top-left, green top-right, blue bottom-left, white bottom-right, black
  interior. Asymmetric in both axes so no flip, mirror or transpose is
  invisible. Pluton's own content, no licence constraints.
- **textured_box.glb** - a unit quad with `TEXCOORD_0` and `uvgrid.png`
  embedded in the buffer. The embedded-image import fixture.
- **textured_box.gltf** + **textured_box.bin** + sibling **uvgrid.png** - the
  same quad with the image referenced by URI. The external-image import
  fixture, and the one that exercises path containment.
- **avocado_draco.glb** - Khronos' **Avocado**, `glTF-Draco` variant, repacked
  as a self-contained GLB with its three PBR maps replaced by `uvgrid.png`.
  Source: <https://github.com/KhronosGroup/glTF-Sample-Assets> (Models/Avocado).
  License: **CC0 1.0 (public domain)**. This is the UV-bearing Draco gate:
  `draco_box.glb` declares NORMAL and POSITION only, so it decodes correctly
  even when UV extraction is entirely broken.

All of the above are regenerated by `make_fixtures.py`, which is committed so
no fixture here is an unexplainable binary blob.
